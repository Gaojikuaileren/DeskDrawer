What it is

A single-purpose desktop organizer for Windows. It draws transparent boards onto your wallpaper and lets you decide which icons go in which board, running from the system tray and nothing else.

Who it is for

People whose desktop is a working surface — current projects, downloads, this week's files — who want it readable without installing a large personalization suite.

What it deliberately is not

Not a launcher, dock, theming engine or file manager. No automatic filing rules, no plugins. The full list of limitations is public.

Why not just make folders?

It is the obvious way to deal with a cluttered desktop, and sometimes it is the right answer. Here is where it stops working.

A folder hides what you filed

The reason a file is on your desktop is that you want to see it. Dragging it into a folder puts it one double-click away, which is the problem you were trying to solve. A drawer groups your desktop icons while leaving every one of them visible.

Folders change where things live

Filing moves files, so every path that pointed at them now points somewhere else. A drawer records only which icons belong together, so nothing on disk moves and nothing that referenced it has to be updated.

Tidying by hand does not stay tidy

A desktop you sort into folders on Monday is loose again by Friday, because downloads and screenshots keep landing on it. New items simply join a drawer, so the arrangement holds without you maintaining it.
